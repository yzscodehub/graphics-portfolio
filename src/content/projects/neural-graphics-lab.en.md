## Project outcome

The neural-denoising page always starts with the deterministic Canvas 2D probe generated by `makeFrames()`, which provides noisy, denoised, reference, and error views. It is not a screenshot from the independent validation set and does not represent a live path-tracing frame.

The project also retains a separately reviewed offline record: the residual CNN has eight convolutional layers and accepts `1×3×256×256` RGB input. When a reviewed ONNX file is deployed, the browser may try ONNX Runtime WebGPU/WASM; a failure returns to the same deterministic probe.

## Evidence boundary

The confirmed metrics come from independently held-out procedural validation scenes, not from the current browser image. They apply only to that self-generated distribution and cannot be turned into production denoising, cross-scene generalization, or universal browser-performance claims. Provenance, training records, and limitations are documented in `training/model-card.md`.
