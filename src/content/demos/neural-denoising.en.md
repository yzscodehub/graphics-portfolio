## What runs

The browser always has a deterministic Canvas 2D probe generated by `makeFrames()`. If `neural-denoiser.onnx` is deployed, the page optionally tries ONNX Runtime WebGPU/WASM and reports measured inference time; load, shape, or execution failures return to the same deterministic probe.

## Evidence and boundary

The separately reviewed model accepts `1×3×256×256` RGB and contains exactly eight convolution layers. Its artifact size and PyTorch/ONNX parity belong to the offline validation record; the current browser Canvas image is not that validation frame.

The confirmed L1 and PSNR values come from 16 held-out procedural scenes in an independent offline run. They apply only to that self-generated Cornell-style distribution; they are not measurements of the current deterministic Canvas probe, browser timing, production denoising, or generalization. Full provenance and limitations live in `training/model-card.md`.
